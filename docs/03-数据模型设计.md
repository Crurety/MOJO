## 1. 数据库设计概述

### 1.1 数据库选型

| 数据库类型 | 用途 | 说明 |
|-----------|------|------|
| MySQL 8.0 | 主数据库 | 存储核心业务数据 |
| Redis | 缓存数据库 | 缓存、会话、队列 |
| MongoDB | 日志数据库 | 存储操作日志、任务日志 |

### 1.2 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 表名 | 小写字母，下划线分隔，复数形式 | users, orders |
| 字段名 | 小写字母，下划线分隔 | user_id, created_at |
| 主键 | id | id |
| 外键 | 关联表名单数_id | user_id |
| 索引 | idx_表名_字段名 | idx_users_email |
| 唯一索引 | uk_表名_字段名 | uk_users_email |

### 1.3 公共字段

所有表都包含以下公共字段：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT | 主键，自增 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |
| deleted_at | DATETIME | 软删除时间 |

## 9. 索引设计

### 9.1 索引设计原则

1. 主键自动创建聚簇索引
2. 外键字段创建普通索引
3. 常用查询条件字段创建索引
4. 唯一约束字段创建唯一索引
5. 组合查询字段创建组合索引
6. 避免过多索引影响写入性能

### 9.2 组合索引设计

| 表名 | 索引名 | 字段 | 说明 |
|------|--------|------|------|
| works | idx_works_public_score | is_public, quality_score | 作品集查询 |
| tasks | idx_tasks_status_created | status, created_at | 任务队列查询 |
| orders | idx_orders_user_status | user_id, status | 用户订单查询 |
| messages | idx_messages_user_read | user_id, is_read | 未读消息查询 |
