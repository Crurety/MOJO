## 2. 用户管理模块

### 2.1 模块概述

用户管理模块负责用户的注册、登录、信息管理、权限管理等核心用户相关功能。

### 2.2 功能清单

| 功能ID | 功能名称 | 功能描述 |
|--------|---------|---------|
| M01-F01 | 用户注册 | 支持邮箱/手机号注册 |
| M01-F02 | 用户登录 | 支持多种登录方式 |
| M01-F03 | 找回密码 | 通过邮箱/手机号重置密码 |
| M01-F04 | 个人信息管理 | 查看/编辑个人信息 |
| M01-F05 | 账户安全设置 | 修改密码、绑定账号 |
| M01-F06 | 实名认证 | 身份证实名认证 |
| M01-F07 | 权限管理 | 查看已开通权限 |

### 2.3 用户注册详细设计

#### 2.3.1 业务流程图

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  开始注册    │────→│ 选择注册方式 │────→│ 填写注册信息 │
└─────────────┘     └─────────────┘     └─────────────┘
                                               │
                                               ↓
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  注册成功    │←────│  创建账户   │←────│  验证信息   │
└─────────────┘     └─────────────┘     └─────────────┘
```

#### 2.3.2 输入参数

| 参数名 | 类型 | 必填 | 说明 | 校验规则 |
|--------|------|------|------|---------|
| registerType | string | 是 | 注册类型 | email/phone |
| account | string | 是 | 邮箱/手机号 | 邮箱格式/手机号格式 |
| password | string | 是 | 密码 | 8-20位，包含字母和数字 |
| verifyCode | string | 是 | 验证码 | 6位数字 |
| nickname | string | 否 | 昵称 | 2-20个字符 |

#### 2.3.3 输出结果

| 字段名 | 类型 | 说明 |
|--------|------|------|
| userId | string | 用户ID |
| token | string | 登录令牌 |
| expiresIn | number | 令牌有效期(秒) |

#### 2.3.4 业务规则

1. 同一邮箱/手机号只能注册一次
2. 验证码5分钟内有效
3. 验证码发送间隔60秒
4. 密码需加密存储(bcrypt)
5. 注册成功自动登录

### 2.4 用户登录详细设计

#### 2.4.1 登录方式

| 登录方式 | 输入参数 | 说明 |
|---------|---------|------|
| 邮箱密码登录 | email + password | 邮箱+密码 |
| 手机号密码登录 | phone + password | 手机号+密码 |
| 手机号验证码登录 | phone + verifyCode | 手机号+验证码 |

#### 2.4.2 安全规则

| 规则 | 说明 |
|------|------|
| 密码错误限制 | 连续错误5次锁定账户30分钟 |
| Token有效期 | 默认24小时，"记住我"7天 |
| 登录日志 | 记录IP、时间、设备信息 |
| 异常登录检测 | 新设备登录发送通知 |

### 2.5 用户权限模型

#### 2.5.1 权限类型

| 权限ID | 权限名称 | 说明 |
|--------|---------|------|
| PERM_SCRIPT | 文字生成脚本权限 | 基础权限 |
| PERM_IMAGE | 图片生成权限 | 独立权限 |
| PERM_VIDEO | 视频生成权限 | 独立权限 |
| PERM_AD | 广告设计权限 | 依赖图片或视频权限 |

#### 2.5.2 权限状态

| 状态 | 说明 |
|------|------|
| active | 权限有效 |
| expired | 权限已过期 |
| exhausted | 次数已用完 |

#### 2.5.3 权限数据结构

```json
{
  "userId": "U20260304001",
  "permissions": [
    {
      "permId": "PERM_SCRIPT",
      "type": "count",
      "totalCount": 100,
      "usedCount": 20,
      "status": "active",
      "expireAt": null
    },
    {
      "permId": "PERM_IMAGE",
      "type": "monthly",
      "totalCount": null,
      "usedCount": 15,
      "status": "active",
      "expireAt": "2026-04-04T23:59:59Z"
    }
  ]
}
```

## 3. 文字生成创作脚本模块

### 3.1 模块概述

文字生成创作脚本是平台的基础功能，为图片生成和视频生成提供内容支撑。支持简化模式（问答引导）和完整模式两种方式。

### 3.2 功能清单

| 功能ID | 功能名称 | 功能描述 |
|--------|---------|---------|
| M02-F01 | 简化模式生成 | 关键字+问答引导生成脚本 |
| M02-F02 | 完整模式生成 | 直接输入所有要素生成脚本 |
| M02-F03 | 脚本编辑 | 编辑已生成的脚本 |
| M02-F04 | 脚本保存 | 保存脚本草稿 |
| M02-F05 | 脚本导出 | 导出脚本文件 |

### 3.3 简化模式详细设计

#### 3.3.1 业务流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ 输入关键字   │────→│ AI分析关键字 │────→│ 生成引导问题 │
└─────────────┘     └─────────────┘     └─────────────┘
                                               │
                                               ↓
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ 生成脚本    │←────│ AI综合分析  │←────│ 用户回答问题 │
└─────────────┘     └─────────────┘     └─────────────┘
```

#### 3.3.2 输入参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| keywords | array | 是 | 关键字列表(1-5个) |
| outputType | string | 是 | 输出类型: image_set/single_image/video |

#### 3.3.3 引导问题生成规则

根据输出类型生成不同的引导问题：

**图片集类型问题:**

| 问题ID | 问题内容 | 必答 | 说明 |
|--------|---------|------|------|
| Q001 | 请描述主要人物角色的形象特征 | 是 | 用于人物设定 |
| Q002 | 请描述故事的主要情节线 | 是 | 用于叙事设计 |
| Q003 | 请选择期望的图片清晰度 | 是 | 720P/1080P/4K |
| Q004 | 请选择期望的图片尺寸 | 是 | 16:9/4:3/1:1/9:16 |
| Q005 | 请描述期望的场景风格 | 否 | 背景、色调等 |

**单张图片类型问题:**

| 问题ID | 问题内容 | 必答 | 说明 |
|--------|---------|------|------|
| Q001 | 请详细描述图片内容 | 是 | 主体、背景、细节 |
| Q002 | 请选择期望的图片清晰度 | 是 | 720P/1080P/4K |
| Q003 | 请选择期望的图片尺寸 | 是 | 16:9/4:3/1:1/9:16 |
| Q004 | 请描述期望的风格 | 否 | 艺术风格、色调 |

**视频类型问题:**

| 问题ID | 问题内容 | 必答 | 说明 |
|--------|---------|------|------|
| Q001 | 请描述视频的主要任务/人物 | 是 | 主体描述 |
| Q002 | 请描述视频的故事线 | 是 | 叙事脉络 |
| Q003 | 请选择期望的视频清晰度 | 是 | 720P/1080P/4K |
| Q004 | 请选择期望的视频时长 | 是 | 根据权限限制 |
| Q005 | 请描述期望的场景风格 | 否 | 背景、风格 |

### 3.4 完整模式详细设计

#### 3.4.1 输入表单设计

**图片集表单:**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| characters | array | 是 | 人物角色列表 |
| storyline | string | 是 | 故事线描述 |
| clarity | string | 是 | 清晰度 |
| size | string | 是 | 尺寸 |
| scenes | array | 否 | 场景建议列表 |
| style | string | 否 | 风格描述 |

**单张图片表单:**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| content | string | 是 | 图片内容描述 |
| clarity | string | 是 | 清晰度 |
| size | string | 是 | 尺寸 |
| style | string | 否 | 风格描述 |

**视频表单:**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| task | string | 是 | 任务/人物描述 |
| storyline | string | 是 | 故事线描述 |
| clarity | string | 是 | 清晰度 |
| duration | number | 是 | 时长(秒) |
| scenes | array | 否 | 场景建议列表 |
| style | string | 否 | 风格描述 |

### 3.5 使用量计算规则

#### 3.5.1 基础权重

| 输出类型 | 基础权重 |
|---------|---------|
| 单张图片 | 1 |
| 图片集(每张) | 1 |
| 视频(每10秒) | 2 |

#### 3.5.2 清晰度系数

| 清晰度 | 系数 |
|--------|------|
| 720P | 1.0 |
| 1080P | 1.5 |
| 4K | 2.5 |

#### 3.5.3 计算公式

```
使用量 = 基础权重 × 清晰度系数 × 数量系数
```

## 4. 图片生成模块

### 4.1 模块概述

图片生成模块基于创作脚本或参考图，调用第三方AI模型生成图片内容。

### 4.2 功能清单

| 功能ID | 功能名称 | 功能描述 |
|--------|---------|---------|
| M03-F01 | 脚本驱动生成 | 基于创作脚本生成图片 |
| M03-F02 | 参考图驱动生成 | 基于参考图生成图片 |
| M03-F03 | 图片二次编辑 | 对生成图片进行编辑 |
| M03-F04 | 图片预览 | 预览生成的图片 |
| M03-F05 | 图片下载 | 下载生成的图片 |

### 4.3 脚本驱动生成详细设计

#### 4.3.1 业务流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ 选择脚本    │────→│ 确认生成参数 │────→│ 提交生成任务 │
└─────────────┘     └─────────────┘     └─────────────┘
                                               │
                                               ↓
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ 通知用户    │←────│ 保存结果    │←────│ AI生成处理  │
└─────────────┘     └─────────────┘     └─────────────┘
```

#### 4.3.2 任务状态流转

```
pending → processing → completed
                    ↘ failed
```

| 状态 | 说明 |
|------|------|
| pending | 排队等待中 |
| processing | 正在生成 |
| completed | 生成完成 |
| failed | 生成失败 |

#### 4.3.3 输入参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| scriptId | string | 是 | 脚本ID |
| generateCount | number | 否 | 生成数量，默认1 |

### 4.4 参考图驱动生成详细设计

#### 4.4.1 输入参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| referenceImage | file | 是 | 参考图片文件 |
| description | string | 是 | 生成要求描述 |
| clarity | string | 是 | 清晰度 |
| size | string | 是 | 尺寸 |
| similarity | number | 否 | 相似度(0-1)，默认0.7 |

#### 4.4.2 文件上传规则

| 项目 | 限制 |
|------|------|
| 格式 | JPG, PNG, WEBP |
| 大小 | 最大10MB |
| 尺寸 | 最小256x256，最大4096x4096 |

### 4.5 二次编辑详细设计

#### 4.5.1 输入参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| imageId | string | 是 | 原图片ID |
| editInstruction | string | 是 | 编辑指令描述 |
| editType | string | 是 | 编辑类型 |

#### 4.5.2 编辑类型

| 类型 | 说明 |
|------|------|
| modify | 修改内容 |
| enhance | 增强效果 |
| style_transfer | 风格迁移 |
| extend | 图片扩展 |

## 5. 视频生成模块

### 5.1 模块概述

视频生成模块基于创作脚本，调用第三方AI模型生成视频内容。视频时长受用户付费权限限制。

### 5.2 功能清单

| 功能ID | 功能名称 | 功能描述 |
|--------|---------|---------|
| M04-F01 | 视频生成 | 基于脚本生成视频 |
| M04-F02 | 视频二次编辑 | 对生成视频进行编辑 |
| M04-F03 | 视频预览 | 预览生成的视频 |
| M04-F04 | 视频下载 | 下载生成的视频 |

### 5.3 视频生成详细设计

#### 5.3.1 输入参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| scriptId | string | 是 | 脚本ID |
| duration | number | 是 | 时长(秒) |
| clarity | string | 是 | 清晰度 |
| style | string | 否 | 视频风格 |

#### 5.3.2 时长限制规则

| 权限类型 | 时长限制 |
|---------|---------|
| 按次付费 | 单次最大60秒 |
| 包月 | 单次最大180秒 |
| 包年 | 单次最大300秒 |

#### 5.3.3 输出规格

| 清晰度 | 分辨率 | 帧率 |
|--------|--------|------|
| 720P | 1280x720 | 30fps |
| 1080P | 1920x1080 | 30fps |
| 4K | 3840x2160 | 60fps |

### 5.4 使用量计算规则

```
视频使用量 = (时长/10) × 清晰度系数 × 基础权重(2)
```

## 6. 广告设计模块

### 6.1 模块概述

广告设计模块基于创作脚本或用户上传的素材，自动生成图文广告或视频广告。

### 6.2 功能清单

| 功能ID | 功能名称 | 功能描述 |
|--------|---------|---------|
| M05-F01 | 脚本驱动广告生成 | 基于脚本自动生成广告 |
| M05-F02 | 素材组合广告生成 | 基于用户素材AI组合生成 |
| M05-F03 | 广告预览 | 预览生成的广告 |
| M05-F04 | 广告下载 | 下载生成的广告 |

### 6.3 广告类型

| 类型 | 说明 | 依赖权限 |
|------|------|---------|
