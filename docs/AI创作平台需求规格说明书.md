## 1. 项目概述

### 1.1 项目背景

本项目是一个集广告设计、视频生成、图片生成、文字生成创作脚本于一体的AI创作平台。平台采用付费使用模式，用户需开通相应功能权限后方可使用，支持按次数、按月、按年多种收费方式。

### 1.2 项目定位

面向企业营销团队、自媒体创作者、广告公司、电商商家、个人用户等群体，提供一站式AI内容创作解决方案。

### 1.3 核心价值

- 降低创作门槛，让非专业用户也能快速产出高质量内容
- 提供完整的创作链路，从脚本到成品一站式完成
- 灵活的付费模式，满足不同用户的使用需求

### 3.2 文字生成创作脚本

#### 3.2.1 功能描述

文字生成创作脚本是平台的基础功能，为图片生成和视频生成提供内容支撑。用户可通过两种模式生成创作脚本。

#### 3.2.2 输入模式

**模式一：简化模式（问答式引导）**

| 步骤 | 用户操作 | 系统响应 |
|------|---------|---------|
| 1 | 输入少量关键字/创作灵感 | 系统识别创作方向 |
| 2 | - | 系统发起问答，逐步收集必要信息 |
| 3 | 回答系统问题 | 系统完善脚本要素 |
| 4 | - | 生成完整创作脚本 |

**模式二：完整模式**

| 用户操作 | 说明 |
|---------|------|
| 直接输入所有必要内容 | 用户一次性提供完整信息，系统直接生成脚本 |

#### 3.2.3 输出类型与要素

根据用户选择的输出类型，系统需要收集不同的要素信息：

**类型一：图片集**

| 要素 | 必填 | 说明 |
|------|------|------|
| 人物角色 | 是 | 角色形象描述 |
| 故事线 | 是 | 图片集的叙事脉络 |
| 清晰度 | 是 | 图片分辨率要求 |
| 大小 | 是 | 图片尺寸规格 |
| 场景建议 | 否 | 背景场景描述 |
| 其他要素 | 否 | 风格、色调等补充信息 |

**类型二：单张图片**

| 要素 | 必填 | 说明 |
|------|------|------|
| 图片内容描述 | 是 | 详细描述图片内容 |
| 大小 | 是 | 图片尺寸规格 |
| 清晰度 | 是 | 图片分辨率要求 |
| 其他要素 | 否 | 风格、色调等补充信息 |

**类型三：视频**

| 要素 | 必填 | 说明 |
|------|------|------|
| 人物/任务 | 是 | 视频主体描述 |
| 故事线 | 是 | 视频叙事脉络 |
| 清晰度 | 是 | 视频分辨率要求 |
| 时长 | 是 | 视频时长要求 |
| 场景建议 | 否 | 背景场景描述 |
| 其他要素 | 否 | 风格、配乐等补充信息 |

#### 3.2.4 脚本编辑

- 支持对生成的脚本进行编辑和修改
- 编辑后可重新生成内容
- 编辑操作会重新计算使用量

### 3.3 图片生成

#### 3.3.1 功能描述

基于创作脚本或用户上传的参考图，生成符合要求的图片内容。

#### 3.3.2 输入方式

| 方式 | 说明 |
|------|------|
| 脚本驱动 | 使用文字生成的创作脚本作为输入源 |
| 参考图驱动 | 用户上传参考图片，系统基于参考图生成新图片 |

#### 3.3.3 输出规格

- 支持生成图片集（多张关联图片）
- 支持生成单张图片
- 输出规格由脚本要素决定

#### 3.3.4 二次编辑

- 支持对生成图片进行二次编辑
- 二次编辑按完整次数重新计算用量

### 3.4 视频生成

#### 3.4.1 功能描述

基于创作脚本生成视频内容，视频时长根据用户付费模型确定。

#### 3.4.2 输入方式

| 方式 | 说明 |
|------|------|
| 脚本驱动 | 使用文字生成的创作脚本作为输入源 |

#### 3.4.3 输出规格

| 要素 | 说明 |
|------|------|
| 时长 | 根据付费模型确定 |
| 风格 | 支持所有合规的视频风格 |
| 清晰度 | 根据脚本要素确定 |

#### 3.4.4 二次编辑

- 支持对生成视频进行二次编辑
- 二次编辑按完整次数重新计算用量

### 3.5 广告设计

#### 3.5.1 功能描述

基于图片和视频素材，组合生成广告内容，支持图文广告和视频广告两种形式。

#### 3.5.2 创作方式

| 方式 | 说明 |
|------|------|
| 脚本驱动 | 根据文字生成的创作脚本自动生成广告 |
| 素材组合 | 用户提供素材集，AI进行创意组合 |

#### 3.5.3 广告类型

| 类型 | 说明 |
|------|------|
| 图文广告 | 基于图片素材组合生成 |
| 视频广告 | 基于视频素材组合生成 |

#### 3.5.4 设计原则

- 不提供固定模板
- AI根据内容和需求自动创意设计

## 4. 用户权限与付费体系

### 4.1 权限模型

```
┌─────────────────────────────────────────────────────────┐
│                     用户权限体系                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐     │
│  │ 文字脚本权限 │  │ 图片生成权限 │  │ 视频生成权限 │     │
│  └─────────────┘  └─────────────┘  └─────────────┘     │
│                         ↓                               │
│              ┌─────────────────────┐                   │
│              │    广告设计权限      │                   │
│              │ (依赖图片/视频权限)  │                   │
│              └─────────────────────┘                   │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 4.2 权限规则

| 规则 | 说明 |
|------|------|
| 独立开通 | 各功能权限独立开通，用户可按需选择 |
| 独立计费 | 各功能独立计费，互不影响 |
| 即时生效 | 付费后权限立即生效，无需审核 |
| 依赖关系 | 广告设计功能依赖图片生成或视频生成权限 |

### 4.3 未付费用户权限

| 功能 | 权限 |
|------|------|
| 浏览简介 | ✅ 可查看 |
| 作品集展示 | ✅ 可观看 |
| 作品下载 | ❌ 不可下载 |
| 功能使用 | ❌ 不可使用 |

### 4.4 付费模式

| 模式 | 说明 |
|------|------|
| 按次数 | 根据使用次数计费 |
| 按月 | 月度订阅，期内不限次数或限额 |
| 按年 | 年度订阅，期内不限次数或限额 |

### 4.5 使用量计算规则

#### 4.5.1 复杂度权重

不同生成内容的复杂度对应不同的计费权重：

| 内容类型 | 复杂度因素 | 权重说明 |
|---------|-----------|---------|
| 单张图片 | 清晰度、尺寸 | 基础权重 × 清晰度系数 × 尺寸系数 |
| 图片集 | 数量、清晰度、尺寸 | 单张权重 × 数量 |
| 视频 | 时长、清晰度 | 基础权重 × 时长系数 × 清晰度系数 |
| 广告设计 | 素材复杂度 | 根据组合素材的复杂度计算 |

#### 4.5.2 二次编辑计算

- 二次编辑按完整次数计算用量
- 不提供折扣
