## 3. 用户故事详细说明

### 3.1 用户模块

#### US-USER-001 用户注册

| 项目 | 内容 |
|------|------|
| **用户故事** | 作为一个未注册访客，我想要注册账户，以便使用平台的各项功能 |
| **优先级** | P0 (必须) |
| **故事点** | 3 |
| **前置条件** | 无 |
| **主流程** | 1. 用户点击"注册"按钮<br>2. 用户选择注册方式(邮箱/手机号)<br>3. 用户填写注册信息<br>4. 用户完成验证(邮箱验证码/短信验证码)<br>5. 系统创建账户并提示注册成功<br>6. 用户自动登录并跳转到首页 |
| **替代流程** | 3a. 用户输入的信息格式不正确<br>　→ 系统提示错误信息，用户重新输入<br>4a. 验证码错误或过期<br>　→ 系统提示验证失败，用户重新获取验证码<br>4b. 邮箱/手机号已被注册<br>　→ 系统提示账户已存在，引导用户登录 |
| **后置条件** | 用户账户创建成功，用户处于登录状态 |

**验收标准:**

- [ ] AC1: 支持邮箱注册方式
- [ ] AC2: 支持手机号注册方式
- [ ] AC3: 邮箱格式验证正确
- [ ] AC4: 手机号格式验证正确(支持中国大陆手机号)
- [ ] AC5: 密码强度要求:至少8位，包含字母和数字
- [ ] AC6: 邮箱验证码6位数字，5分钟内有效
- [ ] AC7: 手机验证码6位数字，5分钟内有效
- [ ] AC8: 验证码发送间隔60秒
- [ ] AC9: 重复邮箱/手机号注册时提示"账户已存在"
- [ ] AC10: 注册成功后自动登录

| 项目 | 内容 |
|------|------|
| **用户故事** | 作为一个已注册用户，我想要登录账户，以便访问我的个人信息和创作内容 |
| **优先级** | P0 (必须) |
| **故事点** | 2 |
| **前置条件** | 用户已注册 |
| **主流程** | 1. 用户点击"登录"按钮<br>2. 用户选择登录方式<br>3. 用户输入登录凭证<br>4. 系统验证凭证<br>5. 登录成功，跳转到首页或之前访问的页面 |
| **替代流程** | 4a. 账户不存在<br>　→ 系统提示"账户不存在"<br>4b. 密码错误<br>　→ 系统提示"密码错误"<br>4c. 账户被禁用<br>　→ 系统提示"账户已被禁用，请联系客服"<br>4d. 连续错误5次<br>　→ 账户锁定30分钟 |
| **后置条件** | 用户登录状态保持，可访问需要登录的功能 |

**验收标准:**

- [ ] AC1: 支持邮箱+密码登录
- [ ] AC2: 支持手机号+密码登录
- [ ] AC3: 支持手机号+验证码登录
- [ ] AC4: 登录失败时显示具体错误原因
- [ ] AC5: 连续错误5次后锁定账户30分钟
- [ ] AC6: 支持"记住我"功能，7天内免登录
- [ ] AC7: 登录成功后记录登录日志(IP、时间、设备)

| **用户故事** | 作为一个已付费用户，我想要通过简单的关键字快速生成创作脚本，以便降低创作门槛 |
| **优先级** | P0 (必须) |
| **故事点** | 8 |
| **前置条件** | 用户已开通文字生成功能权限 |
| **主流程** | 1. 用户进入脚本生成页面<br>2. 用户选择"简化模式"<br>3. 用户输入创作灵感/关键字<br>4. 系统分析关键字并生成引导问题<br>5. 用户回答引导问题<br>6. 系统根据回答生成创作脚本<br>7. 用户查看生成的脚本 |
| **替代流程** | 5a. 用户跳过某些问题<br>　→ 系统使用默认值或智能推测<br>6a. 生成失败<br>　→ 系统提示失败原因，用户可重试 |
| **后置条件** | 脚本生成成功，计入使用量 |

**验收标准:**

- [ ] AC1: 支持输入1-5个关键字
- [ ] AC2: 系统生成3-5个引导问题
- [ ] AC3: 用户可跳过非必答问题
- [ ] AC4: 生成脚本包含完整要素
- [ ] AC5: 生成时间显示进度
- [ ] AC6: 支持重新生成
- [ ] AC7: 生成成功后计入使用量
